# Mausam Personal View

Design a clean and modern mobile homepage for the existing "Mausam" weather app by IMD.

Goal: Create a PERSONALIZED homepage, not a new weather app.

The homepage should adapt based on the user's selected profile:

Health, Fitness, Travel, Family, Agriculture, Commuter, Beach, or Events.

For the default Fitness user, design:

1. Top bar:

- MAUSAM logo/name

- Current location

- Profile icon

2. Current Weather:

- Temperature

- Weather condition

- Feels like

- Humidity

- Wind

3. Personalized AI Insight:

"Best time for running: 6:00 AM – 7:30 AM"

Show a small AI/recommendation icon.

4. Priority weather cards:

- AQI

- UV Index

- Wind

- Rain probability

5. Weather Alert:

"Rain expected at 5 PM"

6. Hourly forecast:

Show 5–6 hours with temperature and weather icons.

7. Bottom navigation:

Home | Forecast | Alerts | Saved | Profile

Design style:

- Simple, clean and professional

- Modern weather-app UI

- Easy to read

- Minimal cards

- Soft blue/white weather theme

- Mobile-first

- Good spacing and typography

Important:

The homepage must clearly show PERSONALIZED information first.

Keep the design simple and practical for an existing MAUSAM app.

Do not add unnecessary screens or complex features.
